# Vídeo da primeira dobra

Coloque aqui:

- `video-hero.mp4` — o vídeo do topo da página (16:9, H.264, de preferência até ~10 MB)
- `video-hero.jpg` — capa opcional, mostrada enquanto o vídeo carrega

Para usar YouTube ou Vimeo, troque a constante `VIDEO_HERO` no `index.html`
pelo link do vídeo. Enquanto não houver vídeo, a página mostra o mockup animado
das aulas no lugar.
